### Courses
Here is a listed of course I took and a short description for each:

* 2400 - Computer Systems
    + This course covered topics involving low-level concepts, such as bit manipulation, memory management, and process control.
* 3022 - Intro to Probability and Statistics
    + This course covered topics such as data managment, probailities, distrubtions, and the various modeling methods.
* 3090 - Intro to Quantum Computing
    + This course covered topics related specifically to quantum alogrithms(no quatum physics), such as quantum bits, ciruirts, entanglement, teleportaion, and alogirthms.
* 3352 - Biological Networks
    + This course used data related to biological networks to demonstrate how networks/graphs can be built, evaluated, and improved. It heavily relied on probability and statistics to model these networks.
* 4253 - Datacenter Management
    + This course covered topics such as large data management(Hadoop vs Spark), large data-transfers(REST vs gRPC), VM creation and management in a datacenter(GCP), and modularization of workflow(Docker & K8s)
* 4273 - Network Systems
    + This course covered topics such as reliably transfering data, transmission collisions & avoidance, modern network pathing problems and algorithms, modern network protocols, and network-based file distribution.
